\chapter{无人机及栖息装置系统设计}
为实现微型无人机自主栖息任务，除控制策略与感知方法外，还需构建满足轻量化、高推重比与柔性黏附集成要求的系统平台。然而，由于 VSERF 柔性黏附器件的承载能力有限，系统设计同时受到结构质量、动力性能、感知能力及执行机构布局等多方面约束。因此，需要从无人机本体结构、附着执行机构、电路系统以及地面协同控制架构等层面对平台进行整体设计与实现，以保证系统具备完成自主接近、稳定悬停与可靠附着的基础能力。

基于上述需求，本章围绕无人机—VSERF 栖息系统的工程实现展开。首先分析无人机平台在质量约束与受限感知条件下的设计原则，并完成机体结构与相关附属部件设计；随后介绍 VSERF 柔性黏附装置及其驱动电路的系统集成方案；最后对地面站视觉处理与通信控制架构进行说明，为后续自主栖息控制算法验证与实验研究提供系统支撑。

\section{无人机系统设计} \label{Drone_system_design}
\subsection{无人机设计原则及挑战}
受限于 VSERF 器件当前的性能边界，为实现稳定黏附，无人机平台需满足以下设计要求：

\begin{enumerate}
\item 总质量不超过 \SI{114}{g}（器件黏附能力有限，详见下文）
\item 最大升力与自身重力之差不小于 \SI{0.4}{N}（黏附过程需要一定预加载作用）
\end{enumerate}

在上述约束条件下，无人机平台设计需要在结构质量、动力性能与黏附需求之间进行综合权衡，并在满足系统功能需求的前提下实现整体性能优化。为提高平台的可实现性，结构设计需尽可能降低非必要质量，以提升系统推重比并减轻黏附器件负载；动力系统则需具备一定的推力裕度，以支持接触过程中的姿态调整与预加载作用。同时，机体布局还需兼顾飞行稳定性、黏附器件安装需求以及接触载荷的有效传递，从而保证无人机在飞行与黏附两种工作状态下均具备良好的稳定性与可靠性。基于上述原则，后续平台设计将围绕轻量化结构、高推重比动力配置以及稳定接触能力展开，以确定满足应用需求的整体方案。

除动力性能、结构刚度及黏附需求之间的权衡外，轻量化设计亦对无人机环境感知系统提出了严格约束。为满足整机质量控制在 \SI{100}{g} 以内的设计目标，无人机可承载的传感器数量与功耗受到显著限制，难以集成气压计、光流传感器、GPS 等多种辅助定位与状态感知设备~\cite{mcguire2017efficient,monteiro2017using}。同时，受限于微型电池的供电能力，机载电子设备的规模与复杂度亦受到约束。因此，无人机控制系统需针对受限感知条件进行优化设计，以适应室内无 GPS 信号、无定高测量条件下的飞行任务，实现仅依赖 IMU 状态估计与视觉传感信息的稳定飞行控制。

\subsection{无人机本体机械结构设计}

在无人机本体设计与平台构建方面，本文遵循轻量化与高结构刚度协同优化的设计原则。核心机架采用厚度为\SI{1.5}{mm}的碳纤维板材经精密机加工而成，该材料具有极高的比强度和比模量。最终制成的机架自重仅\SI{8.3}{g}，在实现极致轻量化的同时，确保了优异的整体力学性能与长期尺寸稳定性。实验验证表明，在电机持续运行5分钟的热负荷工况下，机架中心区域未出现肉眼可辨的热致变形；在电机全功率输出的最大推力状态下，机架整体也未观察到明显的弯曲或失稳现象，充分验证了该承力结构在高动态、高负载飞行条件下的可靠性与鲁棒性。

在系统整体架构设计方面，考虑到微型无人机平台在机载计算资源与能耗方面的限制，本文采用地面站辅助计算的分布式处理架构。具体而言，将实时视觉感知与图像处理任务部署于地面高性能计算设备，并基于 OpenCV 算法框架实现目标识别与状态估计。相较于受限的机载嵌入式平台，地面计算单元能够提供更高的计算性能与处理效率，从而避免额外集成高性能机载计算模块所带来的质量与功耗开销。该架构在满足实时感知需求的同时，为 VSERF 柔性黏附器件及其他关键功能模块的集成预留了更多质量与功率裕度，有利于系统整体性能的实现与优化。

\subsection{无人机相关结构设计}
本文针对无人机栖息任务的特殊载荷与感知需求，对机体底座及 VSERF 支架结构进行了重新设计。与传统多旋翼无人机以动力学性能最优为目标的结构设计不同，本文系统的设计目标同时受视觉传感器布局与附着执行机构偏心载荷的共同约束，从而引入了显著的质心-惯量耦合问题。

\subsubsection{无人机基座设计}
在常规多旋翼系统中，电池通常布置于机体几何中心附近，其主要设计目标为最小化系统转动惯量：
\begin{align}
\mathbf{I} = \sum_i m_i \left( \|\mathbf{r}_i\|^2 \mathbf{I}_3 - \mathbf{r}_i \mathbf{r}_i^T \right),
\end{align}

通过将质量集中于几何中心，可以降低控制输入对角速度响应的耦合程度，从而提升姿态控制带宽与动态响应性能。~\cite{tan2025center}

与传统设计不同，本文无人机需在机体顶部搭载向上观测的视觉传感器，其光轴方向与机体法向一致，用于 AprilTag 观测与视觉伺服控制。然而，由于相机模组及其支架结构存在显著偏心质量分布 $\mathbf{r}_c \neq \mathbf{0}$，导致系统质心发生偏移：
\begin{align}
\mathbf{r}_{COM} = \frac{1}{M} \sum_i m_i \mathbf{r}_i.
\end{align}

当该偏移不可忽略时，重力项将引入附加力矩：
\begin{align}
\boldsymbol{\tau}_g = \mathbf{r}_{COM} \times m \mathbf{g},
\end{align}

该力矩在低质量轻型无人机系统中尤为显著，会导致持续的姿态偏置与控制器稳态补偿负担增加。

因此，本问题可被重新表述为一个结构优化问题：
\begin{align}
\min_{\mathcal{S}} \quad & \|\mathbf{r}_{COM}(\mathcal{S})\|^2 \\
\text{s.t.} \quad & \text{camera upward field-of-view constraint}, \\
& \text{VSERF actuation placement constraint}, \\
& \text{structural symmetry constraint}.
\end{align}

其中 $\mathcal{S}$ 表示机体结构设计变量集合。

针对上述问题，本文设计了如图~\ref{Bottom_design} 所示的底座结构，使电池系统与视觉传感器分别布置于机体几何中心的相对两侧，并通过结构对称性约束保证：
\begin{align}
\mathbf{r}_{battery} \approx -\mathbf{r}_{camera},
\end{align}

从而在一阶近似下实现质心偏移抵消：
\begin{align}
\mathbf{r}_{COM} \approx \mathbf{0}.
\end{align}

该设计本质上利用质量分布的奇对称结构降低系统的静态力矩偏置，使得控制输入不再需要持续补偿重力诱导的偏心力矩。

从控制角度来看，该结构设计的核心收益在于降低姿态动力学中的常值扰动项，使系统动力学可更接近标准形式：
\begin{align}
\mathbf{I}\dot{\boldsymbol{\omega}} = \boldsymbol{\tau} - \boldsymbol{\omega} \times (\mathbf{I}\boldsymbol{\omega}),
\end{align}

而无需额外补偿由质心偏移引起的恒定外力矩项，从而降低控制器稳态误差与积分饱和风险。

通过引入基于对称结构的底座设计，在满足向上视觉观测与 VSERF 执行机构布局约束的同时，实现了对轻量化系统中质心偏移问题的有效抑制。该设计使得系统从“重力偏置显式补偿问题”转化为“近似质心居中系统”，从而提升整体姿态控制稳定性与执行任务的可靠性。

\section{栖息装置系统设计}
\subsection{柔性黏附结构 VSERF 的制备}

实验室目前已具备电压可切换电流变流体柔性黏附器件的制备能力。该器件通过将 VSERF 材料封装于特定结构内，并在外加电场作用下触发其流变特性变化，从而实现黏附力的快速调节。在不同外加电压条件下，VSERF 器件所能提供的法向粘附力测试结果如图 \ref{VSERF_Force} 所示。

\begin{figure}[htbp]
  \centering
  \includegraphics[width = 0.7\textwidth]{VSERF_Force.png}
  \caption{VSERF粘附力随电压变化曲线}\label{VSERF_Force}

实验结果表明，随着施加电压的逐渐升高，VSERF 内部颗粒在电场作用下发生极化并形成稳定的链状结构，其等效剪切强度与界面摩擦力显著增强，从而使器件对接触表面的粘附力呈现出单调上升趋势。

在当前工艺条件下，单个 VSERF 器件所能提供的最大稳定粘附力约为\SI{1.12}{N}，对应可承载约\SI{114}{g}的垂直重物。相较于微型无人机自身质量，该粘附能力具备较为充足的安全裕度，为无人机在垂直或倾斜表面上的稳定栖停提供了基础保障。同时，由于 VSERF 的黏附与脱附过程完全由电信号触发，无需复杂的机械传动结构，其系统集成形式紧凑、控制逻辑简单，尤其适合对质量、体积与能耗高度敏感的微型无人机平台。

\subsection{ VSERF 电路设计}
VSERF电路分为两大部分：供电高压电路及控制电路。高压电路电压约为\SI{2500}{V}，控制电路电压约为\SI{3.3}{V}。以下首先介绍高压电路部分。

在上述实验结果中可以观察到，VSERF 器件产生的黏附力随施加电压升高呈单调增长趋势。然而，当工作电压超过 \SI{3000}{V} 时，器件电极及相关电路存在发生电气击穿的风险，进而可能影响 VSERF 器件的正常运行并降低系统整体可靠性。考虑到所采用的高压发生器为封装式黑箱器件，其内部等效阻抗及输入输出特性难以直接表征，因此有必要对其输入—输出电压关系进行实验测试，测试结果如表 \ref{tab:voltage_relation} 所示。

实验结果表明，当高压发生器输入电压为 \SI{2.0}{V} 时，其输出电压约为 \SI{2500}{V}，能够满足 VSERF 器件工作所需的驱动条件。相较于更高输出电压，该工作点在保证器件具有较强黏附能力的同时，仍保留了一定的电压安全裕度，从而有效降低击穿风险，并兼顾系统性能与运行稳定性。

在低压控制电路控制高压电路时，采用光耦继电器能够有效实现电气隔离，从而提高系统的安全性。其原理是：低压侧控制信号首先驱动光耦内部的发光元件（如 LED）发光，光信号再被高压侧的受光元件接收并触发继电器动作。由于信号通过“光”进行传递，而非直接电连接，因此低压控制端与高压执行端之间不存在导电通路，实现了输入与输出的电气隔离。当高压侧出现浪涌、电压尖峰或故障时，危险电压难以直接传导至低压控制电路，从而有效保护控制芯片及传感器的安全，提高系统的抗干扰能力与可靠性~\cite{agunloye2023low}。

控制电路属于低压驱动部分，其主要功能在于实现对高压电路工作状态的控制。系统通过低压侧驱动光耦继电器实现高压回路的通断：当控制端输入 \SI{3.3}{V} 电平时，光耦继电器导通，高压电路进入工作状态；当输入电压降为 \SI{0}{V} 时，继电器断开，高压电路停止运行。由于该控制过程本质上仅涉及离散逻辑电平切换，因此采用单片机 GPIO 引脚作为控制信号输出端能够有效满足需求，并具备实现简单、控制灵活以及便于程序集成等特点。

为实现与无人机飞行控制系统的协同工作，本项目在查阅飞控主板硬件手册后，选定飞控主板中基于 STM32 单片机的 A02 引脚作为控制输出端口。然而，在 Betaflight 默认配置中，A02 引脚被定义为串行通信接口的 Tx 端口，其功能主要用于数据发送，不具备直接作为通用输入输出端口使用的条件。针对这一限制，本文通过对底层单片机引脚功能进行重新配置，取消其原有串行发送功能，并将其重映射为 GPIO 输出模式，从而实现控制端口功能重定义。经重新配置后，该引脚可依据遥控器或上位机发出的控制指令输出高、低电平信号，以实现对高压电路通断状态的可靠控制。

\section{地面站装置设计}
由于微型无人机载荷能力受限，将图像处理与导航决策任务部署于地面站能够有效降低机载计算负担，从而提高系统集成度并降低机载功耗。因此，地面站主要承担图像数据接收、视觉信息处理以及飞行控制指令生成与发送等任务。

在图像传输方面，无人机飞控板集成了视频发射接口（Video Transmitter, VTX），可通过 \SI{2.4}{GHz} 微波链路实时传输机载摄像头图像。地面站配置对应频段的视频接收设备（Video Receiver, VRX）以获取图像数据。本文采用 STARFISH D1 型 VRX 接收图像信号，该设备能够稳定地将机载摄像头视频流传输至计算机，为后续视觉处理与导航控制提供数据基础。

在图像处理与控制计算方面，地面站采用 Python 语言结合 openCV 库实现视觉信息处理与导航控制算法。选用 Python 的主要原因在于其具有良好的开源生态与丰富的图像处理库支持，能够有效降低算法开发与系统集成复杂度~\cite{van1995python}。同时，实验中图像处理链路的实际刷新频率约为 \SI{25}{Hz}，系统实时性需求相对有限，因此 Python 的计算性能已能够满足实验任务要求，无需采用更低层级的高性能语言进行实现。

控制指令传输方面，地面站通过 Python 程序生成符合 CRSF（Crossfire Serial Protocol）协议的数据帧，并借助 ELRS（Express Long Range System）链路向无人机发送控制指令~\cite{peng2006elrs}。具体而言，控制数据首先通过串口发送至射频发射模块，再由无线链路传输至无人机飞控系统，从而实现对无人机姿态与飞行状态的实时控制。

\section{本章小结}

本章围绕微型无人机及栖息装置系统的整体设计与搭建过程，系统性地介绍了平台在结构设计、动力配置、感知约束、控制架构以及附着执行机构集成等方面的关键技术路线与实现方法。

首先，从无人机平台的设计原则出发，分析了在 VSERF 柔性黏附器件性能约束下系统所需满足的质量、推重比与附着预加载能力等核心指标，并进一步讨论了轻量化设计对机载感知与计算能力所带来的限制。在此基础上，明确了以低质量、高推重比与受限感知条件下稳定控制为核心的系统设计目标。

随后，详细介绍了无人机本体的机械结构设计方法，通过碳纤维材料与大面积镂空减重结构实现了整机轻量化，同时结合有限元仿真验证了不同结构设计在应力与变形层面的性能差异，证明所提出轻量化方案在满足强度与刚度要求的前提下具有良好的工程可行性。在动力性能方面，实验结果表明系统具备较高推力裕度，为复杂任务中的姿态调整与接触控制提供了充足的动力冗余。

在系统架构层面，提出了地面站与机载平台协同的分布式感知与控制框架，将计算密集型视觉处理任务下放至地面端，从而有效降低机载计算与功耗负担，实现了在受限平台条件下的实时视觉伺服控制能力。同时，结合 CRSF 与 ELRS 通信链路完成了控制指令的可靠传输。

在结构设计方面，针对栖息任务中存在的偏心载荷与质心偏移问题，提出了基于对称质量分布的底座优化方案，从动力学角度降低了系统静态扰动力矩，提高了姿态控制稳定性。此外，对 VSERF 支架结构进行了功能化设计，以满足电流变黏附器件的安装与力传递需求。

最后，介绍了 VSERF 柔性黏附器件及其驱动电路的实现方法，包括高压驱动电路设计、输入输出特性测试以及光耦隔离控制方案，从电气安全与系统可靠性角度保证了黏附执行机构的稳定运行。

综上，本章完成了微型无人机—VSERF 栖息系统的整体搭建设计，为后续控制算法设计与栖息实验验证提供了可靠的软硬件及系统基础。
